# Shibunyan Personal Website

Personal portfolio website of **Shibunyan** — fullstack developer specializing in automation systems, moderation bots, and Linux infrastructure.

## Overview

- Responsive terminal-inspired glassmorphism design
- Animated professional focus line
- Technology stack overview
- GitHub profile & email contact

## Tech Stack

- TypeScript
- Vite
- Tailwind CSS
- JetBrains Mono
- Font Awesome

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Lint
npm run lint
```
